# Linux Toolbox — установка

Файлы этого пакета нужно скопировать **в корень существующего `~/pets/linux-toolbox`**, сохранив структуру папок. Пакет не содержит исходников самих утилит и ничего не устанавливает автоматически.

## Проверка

```bash
cd ~/pets/linux-toolbox
./install.sh list
./install.sh check all
```

`check` читает исходники и конфигурации, проверяет синтаксис Python. Не выполняет настройку сетевых маршрутов и не изменяет systemd.

## Установка

```bash
./install.sh install tunnels
./install.sh install vpnctl
./install.sh install work-vpn-audit
```

`tunnels` ставится в `~/.local/bin/tunnels` без `sudo`; остальные инструменты — в `/usr/local/bin/` с `sudo`. Если утилита уже установлена, по умолчанию будет отказ. Для **трёх** указанных утилит разрешена явная замена `--replace`, с резервной копией прежних файлов в `/var/backups/linux-toolbox-*` (для tunnels резервная копия рядом с файлом).

Путь `~/.local/bin` должен присутствовать в `PATH`, чтобы вызвать `tunnels` без полного имени. Пользовательские файлы `~/.config/tunnels` и `~/.local/state/tunnels` не затрагиваются.

При установке vpnctl и work-vpn-audit юниты копируются, но таймеры **не включаются автоматически**. Если нужно запустить таймер после проверки, используйте `sudo systemctl enable --now vpnctl.timer` или `sudo systemctl enable --now work-vpn-audit.timer`. Опцию `--enable-timer` следует применять только после того, как вручную проверены настройки соответствующей утилиты.

При обновлении активных systemd-юнитов с `--replace` возможна немедленная смена поведения уже работающих таймеров. Без предварительного изучения изменений этого делать не стоит.

## bypass v2

Утилита не заменяет уже установленный `/usr/local/bin/bypass`, даже с `--replace`, поскольку старая версия не вела реестр принадлежащих ей маршрутов и правил. Перед обновлением нужны инвентаризация и отдельная миграция. Пакет установщика не делает миграцию автоматически.

## Безопасность

Никогда не добавляйте в Git реальные `/etc/vpnctl.json`, `/etc/bypass-*.json`, `~/.config/tunnels/config.json`, личные ключи, SQLite и приватные конфигурации. Установщик не меняет эти данные. Перед первым коммитом проверьте весь репозиторий на конфиденциальные значения.

## Ограничения

Это предварительные установщики для первичной сборки репозитория, не полноценный конфигурационный менеджер: резервная копия не означает автоматический откат при ошибке; удаление утилит пока выполняется вручную. На рабочей машине сначала используйте `check`, а не `install`.
